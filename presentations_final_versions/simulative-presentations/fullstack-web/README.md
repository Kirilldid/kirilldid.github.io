# 🎯 Fullstack-аналитик: Интерактивная презентация

> Современная веб-презентация о пути становления fullstack-аналитика — от основ до профессионального уровня за 12 месяцев.

## 📖 О проекте

Интерактивная презентация для вебинара, рассказывающая о профессии fullstack-аналитика: что это такое, какие навыки нужны, как развиваться и как найти работу. Презентация состоит из 22 слайдов с современным дизайном, анимациями и интерактивными элементами.

### ✨ Особенности

- 🎨 **Современный дизайн** — градиенты, тени, плавные переходы
- 🖱️ **Интерактивность** — кликабельные карточки с раскрывающимися деталями
- ⌨️ **Удобная навигация** — клавиатура, кнопки, индикатор прогресса
- 📱 **Адаптивность** — оптимизировано для десктопа
- 🎯 **22 слайда** — от основ до поиска работы

## 🚀 Быстрый старт

### Локальный запуск

# Как использовать презентацию


1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/fullstack-analyst-presentation.git
cd fullstack-analyst-presentation
```

2. Откройте `index.html` в браузере:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

3. Нажмите `F11` для полноэкранного режима

**Вот и всё!** Никаких зависимостей, сборки или установки — просто откройте HTML-файл.

## Кастомизация

### Редактирование текста

Все тексты находятся в `index.html`. Найдите нужный слайд по `data-slide="N"` и отредактируйте содержимое.

### Изменение цветов

Цвета используют Tailwind CSS классы:
- `bg-blue-600` — синий фон
- `text-gray-900` — тёмно-серый текст
- `from-blue-50 to-indigo-50` — градиенты

### Добавление слайдов

1. Скопируйте структуру существующего слайда
2. Измените `data-slide="N"` на новый номер
3. Обновите `totalSlides` в `script.js`
4. Добавьте точку прогресса
