ДЕНЬ 1

Что считают аналитики: три метрики

💰

Выручка (Revenue)

Определение: Сколько денег аптека получила от продажи товара = Количество × Розничная цена

Почему важно: Если выручка падает, бизнес потенциально в опасности

📈

Метрики в срезах

Определение: Прибыль с каждого товара = Розничная цена − Закупочная цена

Почему важно: Можно много продавать со скидкой, но не зарабатывать. Маржа показывает реальную прибыль

🧾

Средний чек (Average Check)

Определение: Выручка ÷ Количество чеков

Почему важно: Растёт ли размер покупок? Меняется ли поведение клиентов?

Опытный аналитик знает, когда какой инструмент использовать. Новичок думает, что это конкуренция. На самом деле они работают вместе.

ДЕНЬ 2

SQL — это просто переформатированные вопросы

На человеческом языке:

«Дай мне выручку и маржу каждой аптеки, отсортированные по выручке». Под маржой в данном случае подразумевается разница между закупочной ценой и ценой реализации товара.

На SQL:

SELECT
    store_name,
    SUM(revenue) as total_revenue,
    SUM(margin) as total_margin
FROM sales
GROUP BY store_name
ORDER BY total_revenue DESC;

Объяснение построчно:

  • SELECT = "дай мне" (какие колонки)
  • SUM(revenue) = "сумму выручки" (агрегат)
  • FROM sales = "из таблицы продаж"
  • GROUP BY = "сгруппированную по аптекам"
  • ORDER BY = "отсортированную по"

ДЕНЬ 2

Примеры запросов (шпаргалка)

Пример 1: Выручка по аптекам

SELECT
    store_id,
    COUNT(DISTINCT receipt_id) as receipts_count,
    SUM(revenue) as total_revenue,
    SUM(margin) as total_margin,
    ROUND(AVG(revenue), 2) as avg_receipt
FROM sales
GROUP BY store_id
ORDER BY total_revenue DESC;

Пример 2: Анализ скидок

SELECT
    store_id,
    COUNT(CASE WHEN discount > 0 THEN 1 END) as receipts_with_discount,
    COUNT(*) as total_receipts,
    ROUND(SUM(discount), 2) as total_discount
FROM sales
GROUP BY store_id
ORDER BY total_discount DESC;

Пример 3: Топ-товары

SELECT
    product_name,
    SUM(revenue) as total_revenue,
    SUM(margin) as total_margin
FROM sales
GROUP BY product_name
ORDER BY total_revenue DESC
LIMIT 10;

ДЕНЬ 3

Код = документация 

# Выручка по аптекам
revenue_by_store = sales.groupby('store_id').agg({
    'revenue': 'sum',
    'margin': 'sum',
    'receipt_id': 'count'
}).rename(columns={'receipt_id': 'receipts_count'})

# Средний чек
revenue_by_store['avg_receipt'] = (
    revenue_by_store['revenue'] / revenue_by_store['receipts_count']
)

revenue_by_store.sort_values('revenue', ascending=False)

Этот код — на самом деле описание: мы группируем по аптекам, считаем выручку, маржу, кол-во чеков, потом делим выручку на чеки, получаем средний чек. Коллега прочитает этот код и сразу поймёт, как вы считали.
